# Termux XMR Miner 🚀

A simple and beginner-friendly Monero (XMR) mining toolkit for Android Termux using XMRig.

## ✨ Features

- One-command installation
- Automatic XMRig build
- Monero wallet setup
- Custom mining pool
- Background mining
- Start / Stop / Restart
- Live mining logs
- Mining status
- CPU usage control
- Beginner friendly

---

## 📱 Supported

Designed for Android devices running Termux.

Example:

**Realme C25**

The miner uses XMRig with the Monero RandomX algorithm.

---

## ⚡ Quick Installation

Install Termux and run:

```bash
pkg update -y
pkg install git -y

git clone https://github.com/YOUR_USERNAME/termux-xmr-miner.git

cd termux-xmr-miner

chmod +x install.sh miner/*.sh

./install.sh
